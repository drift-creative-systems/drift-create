LLM INSTRUCTIONS — Drift Creative Systems (WordPress theme)
=============================================================
For any AI assistant working on this theme. Read DESIGN.md for visual rules and MEMORY.md for decisions and open issues.

PROJECT
- Theme: Drift Creative Systems (folder: drift-create), v1.0.0
- Repo: https://github.com/drift-creative-systems/drift-create (public). Branches: main = released, develop = work.
- Purpose: marketing site for Drift apps (Music Suite, WP Agency Kit, SEO)
- Agency: The Bonsai Digital Collective (Devon, UK)
- Stack: WordPress 6.3+, PHP 8.0+, ACF Pro (required), jQuery, plain CSS. No build step. No WooCommerce. Classic editor (block editor disabled).

NAMING
- PHP functions: drift_*   (seed/setup: drift_create_*)
- Constants: DRIFT_CREATE_*
- ACF field names: snake_case. Module sub fields use plain names (title, heading, lead, buttons, section_id).
- ACF field keys: field_drift_{layout}_{name}; layout keys: layout_drift_{layout}; groups: group_drift_*
- CSS: BEM (.block__element--modifier). Module root class = module name with hyphens (.image-text, .split, .faq, .cta)
- JS: wrapped in (function($){ ... })(jQuery); function names and event namespaces prefixed bonsai_
- Copy: UK English. Code: US spelling.

ADDING A MODULE
1. Add the layout in ACF (Page modules), with a section_id field.
2. modules/{layout}/module.php — get_sub_field(), escape all output, return early if empty, no <h1> (hero and content use drift_h1_used(); add a layout to drift_layout_has_h1() if it can print the h1).
3. Optional modules/{layout}/module.css (uses :root tokens, max-width queries like the rest).
4. Add the name to drift_module_layouts() AND the switch in drift_render_modules().
5. Commit acf-json. Update README module table, DESIGN.md §6, CHANGELOG.

ESCAPING
- Text: esc_html(); attributes: esc_attr(); URLs: esc_url(); WYSIWYG: wp_kses_post()
- Inline SVG from drift_mark() is static. It's echoed with a phpcs:ignore comment.
- No iframe fields in this theme yet. If you add one, use bonsai_kses_iframe() (Bonsai standard; function not yet in this theme).

FALLBACKS (never an empty page)
- No ACF: admin notice; front page = hero + content + apps + contact; pages = editor content.
- drift_option() returns a fallback for empty options.
- Unknown flexible layout → error_log, skipped.

TRACKING / CONSENT
- No analytics in the theme. Add GA4 via GTM behind Cookiebot only. No PII in the dataLayer.

RELEASES
- Bump style.css Version + DRIFT_CREATE_VERSION together, add a CHANGELOG section, tag vX.Y.Z on main.
- Release asset must be drift-create.zip with a top-level drift-create/ folder (git archive --prefix=drift-create/). See README "Releasing a new version".
- Version numbers in inc/upgrade.php (0.2.0, 0.3.0) are data-migration milestones. Leave them alone.

DON'T
- Don't add accent colours outside drift_suites().
- Don't hardcode #contact elsewhere or add a second contact section on a page.
- Don't switch the Apps CPT to get_field() for details.
- Don't edit acf-json by hand without updating "modified".
